Краткое описание API

API предназначено для получения и управления данными сервиса через HTTP-запросы. Все методы принимают и возвращают данные в формате JSON.

Основные возможности

  • получение списка сущностей;
  • получение детальной информации по идентификатору;
  • создание новой сущности;
  • обновление существующей сущности;
  • удаление сущности при наличии прав.

Формат запросов

Запросы выполняются по REST-принципам с использованием методов GET, POST, PUT/PATCH и DELETE.

Формат ответов

Успешные ответы возвращают HTTP-статусы 200, 201 или 204. Ошибки возвращаются в едином формате: 

{
  "error": "Описание ошибки"
}

Авторизация

Для защищённых методов требуется передавать токен авторизации в заголовке: 

Authorization: Bearer <token>
